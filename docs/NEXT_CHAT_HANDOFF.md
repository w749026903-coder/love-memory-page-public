## 新对话接续方式

1. 先在本机私有交接记录指定的真实路径工作，不要把新项目或生成物放到系统盘。
2. 修改前运行 `git status --short --branch`，确认工作区状态。
3. 功能和视觉改动完成后，提交并推送 `origin/main`，等待 GitHub Pages 构建。
4. 本公开版主要备份方式是 GitHub 提交和推送，不额外生成本地压缩包，避免多份文件混乱。
5. 公开仓库只记录可公开信息；完整交接见私有原项目的 `docs/READ_ME_FIRST_FOR_NEXT_CHAT.md`。

## 日历数据说明

- 2026 年中国节假日使用官方来源：中国政府网《国务院办公厅关于2026年部分节假日安排的通知》。
- 日历数据分为“节日日期”和“官方放假调休”：节日日期可提前标出，放假天数和调休上班日只按官方通知写入。
