# 我们的纪念日

一个公开版纪念日倒计时静态网页，用于部署到 GitHub Pages。

## 内容

- 纪念日期、称呼、倒计时卡片、时间线和心愿文案都在 `config.js`。
- 当前公开称呼：小朱、婧婧大王。
- 本公开版不包含真人合照和相册页面。
- 轻密码只用于进入仪式感，不是真正的安全保护。

## 本地预览

```powershell
py -m http.server 4173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:4173/
```

## 部署

将仓库发布到 GitHub Pages，站点来源使用 `main` 分支根目录。
